| **Prepares you for** | Lab N Ex k; exam question types … |

One or two sentences: what you can do by the end.

> Writing rule: a first-year student must understand every sentence. Define
> each new term on first use (and link it to GLOSSARY.md), give an example
> before the rule, and avoid unexplained jargon. See CONTRIBUTING.md.

---

## 1. The problem (why)
What goes wrong without this idea? Show it concretely (a schedule, a measurement).

## 2. The idea (what)
Definitions and properties, in a table if there are several.

## 3. The mechanism (how)
Step-by-step, with code and ASCII traces / interleaving tables. Cite slides.

## 4. Why it works
Proof sketches in the lecture's style (invariants, contradiction).

## 5. API cheat-sheet
Only the calls the exercises and labs use, with one-line meanings.

## 6. Exam traps
Common confusions, one bullet each.

## 7. Careful: the notes say…
Where the slides are garbled, inconsistent or incomplete (also add to NOTES_ERRATA.md).

## 8. [EXTRA] …
Material beyond the notes, clearly marked.
