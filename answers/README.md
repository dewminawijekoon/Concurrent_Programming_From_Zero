# Answers (spoilers!)

Reference solutions for every exercise, plus quiz answers, laid out like
`modules/`: `answers/<module>/exercises/...` and `answers/<module>/quiz-answers.md`.

**Try first.** Struggling with a TODO for 20 minutes teaches more than
reading the answer in 2. When you do look, read the comments: they explain
*why* each line is there, which is what the exam asks.

Run the tests against an answer:   `make verify-answers M=05`
Run an answer on its own:          `make run M=05 EX=ex1_peterson ANS=1`
